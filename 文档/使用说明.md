# 快捷键置顶

双击输出结果中的 WindowPin.exe，然后选中要置顶的窗口，按 Win + Ctrl + T。再按一次取消置顶。

右键系统托盘图标可取消本程序设置的全部置顶，或退出。正常退出会取消本程序设置的置顶。

右键托盘菜单中的“开机启动”可启用或关闭当前用户登录时自动运行；打勾表示启用。请保留程序当前位置，移动后需要重新关闭再开启此选项。删除程序前请先关闭开机启动。

若快捷键被 PowerToys 等程序占用，会显示提示并退出。操作管理员权限窗口时，可能需要以管理员身份启动本工具。

这是直接使用 Windows API 编写的独立小程序，无需安装 PowerToys 或 .NET。
